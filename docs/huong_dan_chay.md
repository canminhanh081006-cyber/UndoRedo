# Hướng dẫn build & chạy (Undo/Redo CLI)

## Ký hiệu
- `$`: lệnh chạy trong terminal (MSYS2 UCRT64 / Git Bash)
- `>>`: lệnh nhập bên trong chương trình UndoRedo

## 1) Build (ở `$`)
> Mở Git Bash (hoặc MSYS2 UCRT64) và cd vào thư mục project (nơi có Makefile).

```bash
cd /c/UndoRedo
make clean
make
