# Đề bài tóm tắt
Quản lý lịch sử lệnh điều khiển thiết bị (Undo/Redo).

## Mục tiêu
- Thiết bị giả lập có các tham số: gain (int), range (int), mode (string).
- Người dùng nhập lệnh từ console hoặc file script.
- Hỗ trợ undo/redo nhiều bước.
- Lưu snapshot hoặc log lệnh; load để khôi phục phiên.
- Tìm kiếm lịch sử theo từ khóa.
- Xuất ít nhất 1 file báo cáo (CSV/TXT) để giảng viên kiểm tra.
